# Current manuscript

This folder holds the current build of the paper and its supplementary archive, so that both are
visible without opening the version directory. GitHub lists at most 1,000 entries in a directory,
and `paper_20pc/v4.27/` holds more than that, which placed the PDF in the part of the listing a
browser does not render.

| file | what it is |
|---|---|
| `technosignatures_40pc_v4.27.pdf` | the compiled manuscript, 29 pages |
| `ALMA_Technosignatures_40pc.zip` | the machine-readable supplement: 17 tables, 8,602 rows, column definitions, ALMA identifiers, and reference implementations of the published definitions |

Both are byte-identical to the copies in `paper_20pc/v4.27/`, which remains the authoritative
build directory. The supplement is also intended for deposit with a DOI.
